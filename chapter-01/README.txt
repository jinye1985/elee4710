ELEE 4710 — Chapter 1: Introduction to Power Engineering

Open index.html directly in a modern desktop browser. No server, installation, or internet connection is required for the lesson.
All lesson scripts, styles, equations, photographs, and diagrams are embedded in index.html.
Keep references.html, references.json, and course-lecture.pdf beside index.html to use the separate evidence file and supplied lecture.
External bibliography links require an internet connection only when you choose to visit them.

Use Contents to navigate. Use the global motion control or each demonstration's Play/Pause control.
The annotation toolbar supports pen, highlighting, undo/redo, and viewport PNG export. Press Esc to stop drawing and Shift+A to show or hide the toolbar.
Annotations and text size are stored in this browser; they do not change the HTML file.

The reference document maps concepts, equations, numerical assumptions, interactive diagrams, and external images to inspected sources.
The original 2020 lecture supplies the course structure and the thermal-generation accounting example. Additional demonstrations are explicitly scoped ideal models.
