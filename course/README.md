## Open locally

Double-click `index.html` in this folder. Keep the eight chapter folders beside it. No installation, web server, or start script is required.

To obtain an offline copy from GitHub, [download the main branch ZIP](https://github.com/jinye1985/elee4710/archive/refs/heads/main.zip), extract it, and open `course/index.html`.

## Reading guide

- **Knowledge Point** identifies definitions, principles, and explanations.
- **Interactive Demonstration** identifies animations and adjustable teaching models.
- **Example** headings expand to show worked calculations.
- **References** companions map knowledge points and calculations to lecture material and external sources, including assumptions and source corrections.

Core course content works offline. External reading and video links require an internet connection. See `README.txt` for annotation controls and other usage details.

## Publishing

Keep this whole folder named `course` at the root of the `main` branch. Pages should publish **main / (root)**. The original lecture remains at the site's root address, while this course is served at `/elee4710/course/`.

Update the files in `main/course/` when publishing revisions. Updating `slides-complete-course` alone does not update this published copy.

Original lecture PDFs retain their existing copyrights. Third-party software license files accompany each chapter.
